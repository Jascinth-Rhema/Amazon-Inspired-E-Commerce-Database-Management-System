# Amazon-Inspired E-Commerce Database Management System

## Project Overview
This project is a DBMS semester project that focuses on designing and implementing a relational database for an Amazon-inspired e-commerce platform using MySQL.

## Features
- Customer Management
- Seller Management
- Product Management
- Category Management
- Shopping Cart
- Wishlist
- Order Management
- Payment Management
- Shipment Tracking
- Product Reviews

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Project Status
Database Design Phase
